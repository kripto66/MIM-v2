Modèles à télécharger

Pour chaque catégorie choisie, téléchargez le modèle, remplacez les lignes d'exemple par vos données, puis enregistrez au format CSV.

Comment préparer mon fichier ?

  1. Téléchargez le modèle.
  2. Remplacez les exemples par vos données.
  3. Ne supprimez pas les noms des colonnes.
  4. Enregistrez le fichier au format CSV (UTF-8 de préférence).
  5. Importez-le dans MIM.
  6. Vérifiez l'aperçu.
  7. Confirmez l'importation.
